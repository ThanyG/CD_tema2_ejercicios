## Solucion punto 2. Relación entre las clases

Cuando un socio quiere pedir un libro, primero se comprueba si hay ejemplares disponibles.

1. Si hay ejemplares disponibles, se resta uno de la cantidad disponible y se crea un `Préstamo` que relaciona al `Socio` con el `Libro`. El préstamo se realiza correctamente.

2. Si no hay ejemplares disponibles, no se crea el préstamo y la cantidad de ejemplares permanece igual.

3. Cuando el socio devuelve el libro, el `Préstamo` se da por terminado y se suma nuevamente un ejemplar a los disponibles del `Libro`.

En resumen:

- `Socio`: solicita y devuelve el libro.
- `Libro`: controla los ejemplares disponibles.
- `Préstamo`: relaciona al socio con el libro y registra el préstamo.


### relacion entre las clases

| Operación     | Condición Inicial  | Acciones del Sistema  | Resultado   |
| ------------------------ | ------------------ | ------------------------------------------------------------------------------------------- | ----------- |
| **Préstamo (Con stock)** | Ejemplares &gt; 0  | • Resta 1 ejemplar a `Libro`.<br />• Crea registro de `Préstamo` asociando `Libro` y `Socio`. | **Exitosa** |
| **Préstamo (Sin stock)** | Ejemplares = 0    | • No altera el número de ejemplares.<br />• No crea el registro de `Préstamo`.                | **Fallida** |
| **Devolución**           | Préstamo activo   | • Suma 1 ejemplar a `Libro`.<br />• Cambia estado del `Préstamo` a finalizado.                | **Exitosa** |

##  Solucion punto 3. describir flujo, indicando en cada paso, qué clase actúa y qué colaboradores necesita:

### 1. Se da de alta el libro

Primero se crea un `Libro` y se le ponen 3 ejemplares.

- `Libro`: se encarga de controlar el libro.
- `Ejemplar`: son las 3 copias que hay del libro.

### 2. Se dan de alta los socios

Después se crean dos `Socio`, que son las personas que van a pedir el libro.

### 3. El primer socio pide el libro

El primer `Socio` intenta tomar un `Libro`.

Como hay 3 ejemplares disponibles, puede tomar uno y el préstamo tiene éxito.

Aquí colaboran:

- `Socio`: pide el libro.
- `Libro`: comprueba si hay ejemplares.
- `Ejemplar`: uno de ellos pasa a estar prestado.
- `Préstamo`: relaciona al socio con el libro.

Quedan 2 ejemplares disponibles.

### 4. El segundo socio pide el mismo libro

El segundo `Socio` intenta coger el mismo `Libro`.

También tiene éxito porque todavía quedan 2 ejemplares disponibles.

Queda 1 ejemplar disponible.

### 5. El primer socio devuelve el libro

El primer `Socio` devuelve el ejemplar que tenía.

El `Préstamo` termina y el `Ejemplar` vuelve a estar disponible.

Ahora vuelven a quedar 2 ejemplares disponibles.

### 6. El segundo socio vuelve a pedir el libro

El segundo `Socio` intenta coger el libro otra vez.

Como hay ejemplares disponibles, el préstamo vuelve a tener éxito.

### 7. Resumen

- `Socio`: pide y devuelve los libros.
- `Libro`: comprueba los ejemplares que hay disponibles.
- `Ejemplar`: es cada copia del libro.
- `Préstamo`: relaciona al socio con el libro.

En este caso, los dos socios pueden tener el `libro` prestado porque al principio había 3 ejemplares.
